# Домашняя видеотека

Лабораторная работа 2, вариант 16.

Сервис хранит список фильмов. Можно добавлять, менять и удалять записи,
сортировать их и смотреть статистику. Документация API доступна по адресу `/docs/`.

Для запуска нужны Python и пакеты из `requirements.txt`.
Команды запуска и примеров находятся в файле `Прочитать.txt`.

Все записи учебные. После перезапуска сервиса список возвращается к исходному состоянию.
